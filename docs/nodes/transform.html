Transform nodestransform

Single-input, single-output nodes that reshape the data passing through a branch. Each takes one input and produces one output.

TypeParamsDescription
selectcolumns (list of string, required)Keeps only the given columns, in order.
dropcolumns (list of string, required)Removes the given columns.
limitn (integer, required)Keeps at most the first n rows.
headn (integer, required)Keeps the first n rows.
tailn (integer, required)Keeps the last n rows.
explodecolumns (list of string, required)Explodes list-typed columns into multiple rows, one per element.
group_byby (list of string, required), aggregations (object of string to string, required)Groups rows by the given columns and aggregates the rest using one of sum, mean, min, max, count, median, std, first, last.
logcolumns (list of string, required), base (float, optional)Applies a logarithm to the given columns, using the natural log unless base is given.
zscore_normalizecolumns (list of string, required)Rescales the given columns to zero mean and unit standard deviation.
minmax_normalizecolumns (list of string, required)Rescales the given columns to the [0, 1] range based on their min and max.
fill_meancolumns (list of string, required)Fills nulls in the given columns with each column's mean.
fill_nullcolumns (list of string, required), value (any, required)Fills nulls in the given columns with a fixed value.
drop_nullscolumns (list of string, optional)Drops rows with a null in any of the given columns, or any column if omitted.
drop_duplicatessubset (list of string, optional), keep ("first" | "last" | "any" | "none", default "first")Removes duplicate rows, optionally scoped to a subset of columns.
renamemapping (object of string to string, required)Renames columns from old name to new name.
sortby (list of string, required), descending (bool, default false)Sorts rows by one or more columns.
casttypes (object of string to string, required)Casts columns to the named Polars dtype, for example Int64 or Float64.
filterexpression (string, required)Keeps rows where the sandboxed expression evaluates to true.
deriveexpression (string, required), column (string, required)Adds or replaces a column with the result of the sandboxed expression.

Tabular Manner engine reference. Node types, params, and event names reflect the built-in registry; custom node types added through NodeLibrary are usable the same way once registered.
