The playground runs the same two-phase algorithm as engine.execution.validate / execute: a DFS cycle check first (colors a node GRAY on entry, BLACK on exit — revisiting a GRAY node means a cycle), then, only if the graph is valid, a ready-queue traversal that runs a node once every one of its parents has completed.
